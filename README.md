# Иммунология — тренажёр

Интерактивный тест на 100 вопросов: порядок вопросов и варианты перемешиваются при каждом запуске.
Ответы сверены с официальным ключом преподавателя (12 вопросов, где ключ расходится с научной
трактовкой, помечены в тренажёре плашкой «ключ преподавателя»).
